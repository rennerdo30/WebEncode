# Support

## Where to Get Help

- Read the project documentation in `README.md` and `docs/`.
- Open a GitHub Issue for reproducible bugs or feature requests.

## Before Opening an Issue

Please include:

- Steps to reproduce
- Expected vs actual behavior
- Relevant logs and environment details
- Version/commit information

## Security Issues

Do not report security vulnerabilities in public issues.
Use the private disclosure path described in `SECURITY.md`.
